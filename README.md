# caiogrc.github.io

Site raiz do GitHub Pages do usuario `caiogrc`. Existe so para servir o `app-ads.txt` do Wizard Defense (`com.caiog.wizarddefense`) na raiz do dominio, onde o AdMob procura.

A fonte do arquivo vive em `docs/app-ads.txt` no repositorio privado do jogo: ao mudar la, replicar aqui.

A politica de privacidade continua em https://caiogrc.github.io/wizard-defense-privacy/ (repositorio `wizard-defense-privacy`).
